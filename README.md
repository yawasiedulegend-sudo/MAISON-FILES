# Maison Boutique Website

This folder contains a polished static fashion website for Maison Boutique with:

- Home, shop, about, contact, and checkout pages
- Product details with size, color, availability, and quantity information
- WhatsApp integration for direct customer support and ordering
- Review submission and like/reaction support using browser local storage
- Security-focused meta tags and a basic sitemap and robots file

Open index.html in a browser to view the site.

## Deployment

- Frontend: GitHub Pages
- Backend: Render, Railway, or Fly.io
- API base: update config.js with the hosted backend URL
